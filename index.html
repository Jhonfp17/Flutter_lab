Definición de conceptos

(Que es Flutter)

Es un conjunto de herramientas, componentes, librerías y documentación que los desarrolladores necesitamos para crear aplicaciones para una plataforma específica. Piensa en él como una "caja de herramientas" completa que te da el fabricante (como Google para Android o Apple para iOS) para que no tengas que programar todo desde cero.

SDK (Software Development Kit)

Es un conjunto de herramientas, componentes, librerías y documentación que los desarrolladores necesitamos para crear aplicaciones para una plataforma específica. Piensa en él como una "caja de herramientas" completa que te da el fabricante (como Google para Android o Apple para iOS) para que no tengas que programar todo desde cero.

Desarrollo Mobile

Es el proceso de diseño, creación y despliegue de aplicaciones de software destinadas a ejecutarse en dispositivos móviles (smartphones y tablets). Puede ser nativo (programado exclusivamente para un sistema operativo como Kotlin en Android o Swift en iOS) o híbrido/multiplataforma (usando frameworks como Flutter o React Native para un solo código que sirva en ambos).

StatefulWidget (Widget con Estado)

En frameworks como Flutter, es un componente de la interfaz gráfica que sí puede cambiar sus datos o su aspecto en tiempo de ejecución debido a la interacción del usuario o eventos externos. Tiene memoria interna. Un ejemplo claro es un botón de "Me gusta" (que cambia de color al presionarlo) o un contador que va aumentando.

StatelessWidget (Widget sin Estado)

A diferencia del anterior, este es un componente pasivo e inmutable. No cambia su estado ni su diseño una vez que se dibuja en la pantalla. Es ideal para elementos fijos que solo muestran información estática que no se va a modificar, como un texto de título, un logo de la empresa o un icono decorativo.
